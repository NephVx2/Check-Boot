# Check-Boot
Read-only PowerShell script that audits the entire Windows 10/11 boot chain: BCD, Secure Boot, TPM, UEFI/EFI, boot drivers, BitLocker, WinRE, SMART, VBS/HVCI. Weighted per-category scoring, drift detection via a persistent baseline, HTML/JSON/CSV reports, 12-assertion self-test, and full French/English Windows compatibility.
